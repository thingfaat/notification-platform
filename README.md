# Multi-Tenant Notification Platform

## 1. 项目介绍

面向企业内部业务系统的多租户统一消息通知平台，为不同租户和应用提供短信、邮件、站内信等统一发送能力，并通过消息队列实现异步处理、削峰填谷、失败重试、消费幂等、渠道路由和发送状态追踪。
